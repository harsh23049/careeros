The CareerOS mental model
Whenever we build a new API, ask yourself these 7 questions:

1. What request is coming in?
2. Which route catches it?
3. Which controller handles it?
4. What business logic belongs in the service?
5. What database operation belongs in the repository?
6. Which model/external service is involved?
7. What response goes back to the client?

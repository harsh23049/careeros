# AI Architecture

## Overview

CareerOS uses Artificial Intelligence as an assistant rather than an autonomous decision maker.

AI provides recommendations while the final decision always remains with the user.

---

# AI Responsibilities

- Analyze Job Descriptions
- Recommend Best Resume
- Generate Cover Letters
- Generate Recruiter Emails
- Answer HR Questions
- Resume Improvement Suggestions

---

---

# Why AI Calls Go Through Backend

Benefits

- API Key Security
- Prompt Management
- Logging
- Rate Limiting
- Easier Model Switching

The frontend and extension never communicate directly with AI services.

---

# Prompt Engineering

CareerOS stores reusable prompts for

- Resume Selection
- Cover Letter
- Cold Email
- HR Questions

Each prompt is maintained separately.

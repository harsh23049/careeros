# User Stories

## Resume Management

### US-01

As a user,

I want to upload multiple resumes,

So that I can use different resumes for different job roles.

---

### US-02

As a user,

I want to organize resumes into categories,

So that I can easily find the appropriate resume.

---

### US-03

As a user,

I want AI to recommend the best resume,

So that I don't have to choose manually.

---

# Job Management

### US-04

As a user,

I want to save job descriptions,

So that I can apply later.

---

### US-05

As a user,

I want to view all saved jobs,

So that I can track opportunities.

---

### US-06

As a user,

I want to update my application status,

So that I always know my progress.

---

# AI Features

### US-07

As a user,

I want AI to analyze job descriptions,

So that I understand the required skills.

---

### US-08

As a user,

I want AI to generate personalized cover letters,

So that every application feels tailored.

---

### US-09

As a user,

I want AI to generate recruiter cold emails,

So that I can contact recruiters professionally.

---

### US-10

As a user,

I want AI to answer company-specific application questions,

So that I save time writing repetitive responses.

---

# Chrome Extension

### US-11

As a user,

I want the extension to detect job pages automatically,

So that I don't need to copy job descriptions manually.

---

### US-12

As a user,

I want the extension to autofill application forms,

So that repetitive typing is eliminated.

---

### US-13

As a user,

I want the extension to upload the recommended resume,

So that I can complete applications faster.

---

### US-14

As a user,

I want the extension to save jobs to CareerOS,

So that I can track all my applications.

---

# Dashboard

### US-15

As a user,

I want a dashboard showing all my applications,

So that I can monitor my job search.

---

### US-16

As a user,

I want to view previously generated AI documents,

So that I can reuse them whenever required.

---

### US-17

As a user,

I want to search and filter applications,

So that I can quickly find specific jobs.

---

### US-18

As a user,

I want to manage my profile and settings,

So that my personal information stays updated.

---

# System

### US-19

As a user,

I want my data to be securely stored,

So that my resumes and application history remain safe.

---

### US-20

As a user,

I want all my career-related information in one platform,

So that I no longer need multiple spreadsheets, notes, and documents.
